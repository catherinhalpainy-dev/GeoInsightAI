# 滨江地块开发条件分析

该目录提供 GeoInsight AI 的地块空间分析与辅助审查示例工程。

## 示例内容

- `demo.geoinsight`：首页“一键打开示例项目”使用的完整工程模板。
- `source/landuse.geojson`：土地利用现状主数据。
- `source/planning.geojson`：规划用途。
- `source/restrictions.geojson`：限制建设区域。
- `source/roads.geojson`：道路。
- `source/water.geojson`：水系。
- `source/administrative-boundary.geojson`：行政区边界。
- `source/public-facilities.geojson`：学校、医疗、交通和公共服务设施点。

目标地块 ID：`parcel-target-001`。

数据采用确定性脚本生成，按照“道路与水系骨架 → 城市街区 → 不同尺度地块 → 规划与限制区域”的顺序组织：

- 40 个地块分布在滨水、居住、商业和产业街区内，面积约为 0.29–5.98 公顷；
- 道路包含主干路、次干路和支路，地块边界尽量沿道路廊道组织；
- 规划区跨越多个地块，目标地块同时命中商业服务和公共服务两个规划用途；
- 限制区由河道保护带、生态斑块、基础设施控制带和防洪调蓄区构成；
- 水系采用多节点缓曲线，公共服务设施点沿街区与道路节点分布；
- 生成前会校验 Polygon 合法性、面积一致性以及目标地块的规划、限制、道路、水系和行政区空间关系。

目标地块与规划用途、限制建设区域具有经过程序验证的空间叠加关系，周边 500 米内包含多条道路和一条水系，并完整位于滨江中区行政边界内。

本示例为空间分析产品演示用途的合成 GIS 数据，不使用或复制任何第三方地籍、规划或自然资源数据。它仅模仿城市地块、道路、规划用途、限制区域、水系和行政区的空间结构，不代表真实地理现状、真实规划数据、自然资源审批结果以及任何法律或政策结论。

如需重新生成数据，在仓库根目录执行 `npm run demo:generate`。
